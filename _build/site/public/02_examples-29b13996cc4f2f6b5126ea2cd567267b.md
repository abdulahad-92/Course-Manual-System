### Example 1: Commercial Bank Loan Screening (`if / elif / else`)

**Setup**: A small business loan application is evaluated based on credit score and annual revenue.  
**Point**: Demonstrate compound boolean logic using `and` and chained relational operators (`600 <= score <= 699`).

```python
credit_score = 680
annual_revenue = 650000  # PKR 650,000

print("--- LOAN APPLICATION STATUS ---")

if credit_score >= 700 and annual_revenue >= 500000:
    print("Decision: Loan Approved — Prime Tier Rate (12%)")
elif 600 <= credit_score <= 699 and annual_revenue >= 500000:
    print("Decision: Loan Approved — Standard Tier Rate (15%)")
elif annual_revenue < 500000:
    print("Decision: Loan Denied — Insufficient Annual Revenue")
else:
    print("Decision: Loan Denied — High Credit Risk")
```

### Example 2: Batch Inventory Revenue Auditor (`for` loop & accumulator)

**Setup**: Iterate across a list of daily retail transaction totals to compute weekly revenue and flag any high-value sale day.  
**Point**: Demonstrate definite iteration (`for item in list:`) and conditional checks inside a loop.

```python
daily_sales = [120000, 85000, 210000, 95000, 310000, 140000, 90000]
total_weekly_revenue = 0
high_value_days = 0

for day_idx, sale_amount in enumerate(daily_sales, start=1):
    total_weekly_revenue += sale_amount
    if sale_amount >= 200000:
        high_value_days += 1
        print(f"Day {day_idx}: High-Value Transaction Flagged -> PKR {sale_amount:,.2f}")

print("------------------------------------------")
print(f"Total Weekly Revenue : PKR {total_weekly_revenue:,.2f}")
print(f"High-Value Sales Days: {high_value_days}")
```

### Example 3: Interactive PIN Validation Sentinel (`while` loop)

**Setup**: Simulate an ATM login authentication screen that allows up to 3 PIN entry attempts.  
**Point**: Demonstrate indefinite iteration (`while`), counter variables, and loop termination with `break`.

```python
CORRECT_PIN = "1030"
max_attempts = 3
attempts = 0

while attempts < max_attempts:
    # In live classroom demo, replace hardcoded value with: input("Enter ATM PIN: ")
    user_attempt = "1030" if attempts == 1 else "0000"  # Simulated input
    attempts += 1
    
    if user_attempt == CORRECT_PIN:
        print(f"Attempt {attempts}: PIN Accepted. Access Granted.")
        break
    else:
        remaining = max_attempts - attempts
        print(f"Attempt {attempts}: Incorrect PIN. Attempts remaining: {remaining}")
else:
    print("ACCOUNT LOCKED: Maximum authentication attempts exceeded.")
```

### Spot the Bug: The Assignment vs. Equality Trap

```python
# BROKEN CODE - Classroom Debugging Exercise
# Ask students: Why does this script throw a SyntaxError?

customer_tier = "Standard"

if customer_tier = "VIP":
    print("20% VIP Discount Applied")
else:
    print("Standard Pricing")
```

```{dropdown} Instructor Solution & Explanation
**Why it fails:**
In Python, a single equals sign (`=`) is the **assignment operator**, used to assign a value to a variable. It cannot be used inside an `if` expression to compare two values.

**How to fix it:**
Use the double equals sign (`==`), which is the **relational equality operator**:
```python
customer_tier = "Standard"

if customer_tier == "VIP":
    print("20% VIP Discount Applied")
else:
    print("Standard Pricing")
```
