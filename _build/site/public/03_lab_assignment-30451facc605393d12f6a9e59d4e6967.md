### Problem Statement

You have been hired by **IBA Electronics Store** to build a Python command-line utility that computes sales commission and net pay for retail sales associates.

#### Functional Requirements:
1. Prompt the user to input the following information:
   - Sales Associate Name (String)
   - Monthly Base Salary in PKR (Float)
   - Total Sales Generated this Month in PKR (Float)
   - Commission Rate Percentage (Float, e.g., enter `7.5` for 7.5%)
2. Compute the **Commission Amount** earned:
   $$\text{Commission} = \text{Total Sales} \times \left(\frac{\text{Commission Rate}}{100}\right)$$
3. Compute the **Total Monthly Pay**:
   $$\text{Total Pay} = \text{Base Salary} + \text{Commission Amount}$$
4. Output a cleanly formatted **Monthly Compensation Summary** display where all monetary figures are formatted with thousands separators (`50,000.00`) and rounded to exactly two decimal places.

def main():
    print("--- IBA Electronics Compensation Tool ---")
    
    # Input capture with explicit type conversion
    name = input("Enter Sales Associate Name : ").strip()
    base_salary = float(input("Enter Monthly Base Salary  : "))
    monthly_sales = float(input("Enter Total Monthly Sales  : "))
    commission_pct = float(input("Enter Commission Rate (%)  : "))
    
    # Computation
    commission_amount = monthly_sales * (commission_pct / 100.0)
    total_payout = base_salary + commission_amount
    
    # Formatted Output Display
    print("\n=========================================")
    print("      MONTHLY COMPENSATION SUMMARY")
    print("=========================================")
    print(f"Associate Name  : {name}")
    print(f"Base Salary     : PKR {base_salary:,.2f}")
    print(f"Monthly Sales   : PKR {monthly_sales:,.2f}")
    print(f"Commission ({commission_pct}%): PKR {commission_amount:,.2f}")
    print("-----------------------------------------")
    print(f"TOTAL PAYOUT    : PKR {total_payout:,.2f}")
    print("=========================================")

if __name__ == "__main__":
    main()
