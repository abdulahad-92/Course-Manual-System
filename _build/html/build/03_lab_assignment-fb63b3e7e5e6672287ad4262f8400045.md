### Problem Statement

You are building the promotional pricing module for **IBA Books Online**. Your program must validate customer inputs using loops and determine promotional pricing using conditional logic.

#### Functional Requirements:
1. Use a `while` loop to prompt the user for their **Customer Tier** (`Standard`, `Silver`, or `Gold`) until a valid tier string is entered.
2. Prompt for the total **Order Amount in PKR** (must be a positive number).
3. Apply the following conditional discount rules:
   - **Gold Tier**: 20% discount on orders over PKR 10,000; 15% discount on all other orders.
   - **Silver Tier**: 10% discount on orders over PKR 10,000; 5% discount on all other orders.
   - **Standard Tier**: 5% discount on orders over PKR 15,000; 0% discount otherwise.
4. If the discounted total exceeds PKR 5,000, shipping is **FREE** (PKR 0). Otherwise, shipping is PKR 350.
5. Print an itemized receipt showing Order Amount, Discount Applied, Shipping Fee, and Final Payable Amount.

def main():
    print("--- IBA Books Online Checkout ---")
    
    # Input validation loop
    valid_tiers = ["Standard", "Silver", "Gold"]
    tier = ""
    while tier not in valid_tiers:
        tier = input("Enter Customer Tier (Standard/Silver/Gold): ").strip().capitalize()
        if tier not in valid_tiers:
            print("Invalid tier. Please enter Standard, Silver, or Gold.")
            
    order_amount = float(input("Enter Order Amount (PKR): "))
    
    # Discount logic
    discount_pct = 0.0
    if tier == "Gold":
        discount_pct = 0.20 if order_amount > 10000 else 0.15
    elif tier == "Silver":
        discount_pct = 0.10 if order_amount > 10000 else 0.05
    elif tier == "Standard":
        discount_pct = 0.05 if order_amount > 15000 else 0.0
        
    discount_amount = order_amount * discount_pct
    discounted_subtotal = order_amount - discount_amount
    
    # Shipping fee logic
    shipping_fee = 0.0 if discounted_subtotal >= 5000 else 350.0
    total_payable = discounted_subtotal + shipping_fee
    
    # Formatted Receipt
    print("\n=========================================")
    print("          ITEMIZED CHECKOUT RECEIPT")
    print("=========================================")
    print(f"Customer Tier    : {tier}")
    print(f"Order Subtotal   : PKR {order_amount:,.2f}")
    print(f"Discount ({int(discount_pct*100)}%)   : -PKR {discount_amount:,.2f}")
    shipping_str = "FREE (PKR 0.00)" if shipping_fee == 0 else f"PKR {shipping_fee:,.2f}"
    print(f"Shipping Fee     : {shipping_str}")
    print("-----------------------------------------")
    print(f"TOTAL PAYABLE    : PKR {total_payable:,.2f}")
    print("=========================================")

if __name__ == "__main__":
    main()
