### Lecture Content

#### 1. Conditional Branching (`if / elif / else`)
- **Concept**: Conditional structures allow automated decision-making based on boolean evaluations.
- **The "Excel Rosetta Stone" Metaphor**: Help students transition from spreadsheet formulas to Python syntax:

| Logic Concept | Excel Formula | Python Equivalent |
| :--- | :--- | :--- |
| **Basic If** | `=IF(A2>100, "Free Ship", "Charge Ship")` | `if order_total > 100:` |
| **Nested Else-If** | `=IF(B2="VIP", "20% Off", IF(B2="NEW", "10%", "0%"))` | `elif customer_tier == "VIP":` |
| **Compound And/Or** | `=IF(AND(A2>100, B2="VIP"), "Priority", "Standard")` | `if total > 100 and tier == "VIP":` |

#### 2. Definite Loops (`for` & `range()`)
- **Concept**: A `for` loop executes a block of code once for each item in a sequence or over a generated numeric range.
- **Classroom Demo (Monthly Revenue Totaler)**:
  ```python
  monthly_sales = [120000, 145000, 98000, 160000]
  total = 0
  for sale in monthly_sales:
      total += sale
  print(f"Total Quarterly Sales: PKR {total:,.2f}")
  ```

#### 3. Indefinite Loops (`while` & Sentinel Validation)
- **Concept**: A `while` loop repeats continuously until a terminating boolean condition becomes false. Excellent for interactive menus and data validation.
- **Classroom Demo (Input Validation Loop)**:
  ```python
  age = -1
  while age < 0 or age > 100:
      age_str = input("Enter valid age (0-100): ")
      if age_str.isdigit():
          age = int(age_str)
  print(f"Validated Age: {age}")
  ```

### Common Student Mistakes
1. **Assignment vs. Equality**: Using `=` instead of `==` inside an `if` condition (`if tier = "VIP":` throws a `SyntaxError`).
2. **Infinite `while` Loops**: Forgetting to update the loop control variable inside a `while` loop, causing the terminal to hang.
3. **Indentation Errors**: Inconsistent indentation (mixing tabs and spaces or wrong nesting level for `else`).
