### Example 1: Basic Variable Assignment & Type Inspection

**Setup**: Introduce students to how Python stores different data types and how `type()` reveals the underlying class.  
**Point**: Show that variables can hold strings, integers, floats, and booleans without explicit declarations.

```{code-cell} python3
# Retail product inventory record
product_code = "SKU-9942"
unit_price = 1450.75
units_in_stock = 120
is_taxable = True

print("Product Code :", product_code, "| Type:", type(product_code))
print("Unit Price   :", unit_price,   "| Type:", type(unit_price))
print("In Stock     :", units_in_stock, "| Type:", type(units_in_stock))
print("Taxable      :", is_taxable,     "| Type:", type(is_taxable))
```

**Expected Output**:
```
Product Code : SKU-9942 | Type: <class 'str'>
Unit Price   : 1450.75 | Type: <class 'float'>
In Stock     : 120 | Type: <class 'int'>
Taxable      : True | Type: <class 'bool'>
```

### Example 2: Payroll & Tax Calculation with f-Strings

**Setup**: Demonstrate a simple weekly payroll calculation for an hourly employee.  
**Point**: Emphasize how `f"{val:,.2f}"` automatically inserts commas for thousands and formats currency to exactly two decimal places.

```{code-cell} python3
employee_name = "Ali Khan"
hours_worked = 42.5
hourly_rate = 950.0

# Calculate earnings
gross_pay = hours_worked * hourly_rate
tax_withheld = gross_pay * 0.05
net_pay = gross_pay - tax_withheld

print(f"Employee Name : {employee_name}")
print(f"Gross Pay     : PKR {gross_pay:,.2f}")
print(f"Tax (5%)      : PKR {tax_withheld:,.2f}")
print(f"Net Earnings  : PKR {net_pay:,.2f}")
```

**Expected Output**:
```
Employee Name : Ali Khan
Gross Pay     : PKR 40,375.00
Tax (5%)      : PKR 2,018.75
Net Earnings  : PKR 38,356.25
```

### Spot the Bug: The String Addition Trap

```{code-cell} python3
# BROKEN CODE - Classroom Debugging Exercise
# Ask students: Why does this print '500250' instead of 750?

revenue_day1 = "500"
revenue_day2 = "250"
total_revenue = revenue_day1 + revenue_day2

print("Total Two-Day Revenue:", total_revenue)
```

```{dropdown} Instructor Solution & Explanation
**Why it fails:**
The variables `revenue_day1` and `revenue_day2` contain text strings (`str`), denoted by the quotation marks. The `+` operator on strings performs **concatenation** (joining text end-to-end) rather than numeric addition.

**How to fix it:**
Cast the values to `int` or `float` before arithmetic:
```python
revenue_day1 = 500
revenue_day2 = 250
total_revenue = revenue_day1 + revenue_day2
print(f"Total Two-Day Revenue: PKR {total_revenue:,}")
```
